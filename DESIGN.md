# Design System: LÚCIDA Energía

## Overview

**Creative North Star: "La factura se vuelve transparente"**

El sistema visual convierte información energética opaca en una secuencia progresivamente clara. Combina fotografía documental a gran escala, composición editorial y datos ordenados con precisión. La energía se representa como flujo, luz y comprensión; nunca mediante clichés tecnológicos, bombillas flotantes o interfaces futuristas.

La experiencia debe sentirse humana y confiable antes que corporativa. El movimiento acompaña el significado: revela, organiza y conecta información sin interferir con el desplazamiento nativo.

**Key Characteristics:**

- Fotografía humana y contextual a pantalla completa.
- Titulares de escala expresiva con lectura inmediata.
- Datos y líneas inspirados en una factura, tratados como material editorial.
- Un único acento luminoso reservado para acciones y momentos de claridad.
- Ritmo alternado entre escenas inmersivas y pausas de lectura.

## Colors

Estrategia comprometida: un verde petróleo domina las escenas profundas, una superficie mineral facilita la lectura y un verde luminoso identifica acciones y revelaciones.

**The One Current Rule.** El acento luminoso aparece en una sola corriente visual por escena; no se dispersa como decoración.

## Typography

La tipografía de titulares tendrá carácter editorial-industrial y formas compactas; el cuerpo utilizará una sans humanista altamente legible. Los nombres exactos y sus métricas se consolidarán durante la primera implementación.

**The One Glance Rule.** El mensaje principal de cada sección debe entenderse con una sola mirada y no depender de texto animado para ser legible.

## Layout

La composición utiliza una cuadrícula de doce columnas en escritorio y una columna priorizada en móvil. Alterna escenas de ancho completo, texto asimétrico y bloques de lectura con medida máxima controlada. El espacio vertical crea capítulos, no una colección uniforme de tarjetas.

En móvil, toda narrativa horizontal o fijada se convierte en una secuencia vertical. Ningún contenido esencial depende de hover, parallax o pinning.

## Elevation & Depth

La profundidad proviene de fotografía, superposición tipográfica, recortes y cambios tonales. Las sombras son excepcionales y funcionales; el sistema evita glassmorphism y paneles flotantes genéricos.

## Shapes

Las superficies principales son rectas y editoriales. Los controles pueden utilizar radios suaves y consistentes para comunicar cercanía, pero las fotografías y capítulos conservan recortes amplios y decididos.

## Do's and Don'ts

### Do:

- **Do** utilizar movimiento para explicar el análisis de una factura.
- **Do** preservar el scroll nativo y ofrecer una experiencia equivalente con movimiento reducido.
- **Do** reservar el color más luminoso para CTA, foco y estados relevantes.
- **Do** usar fotografía auténtica de hogares, comercios y personas.

### Don't:

- **Don't** inventar cifras de ahorro, clientes, testimonios o certificaciones.
- **Don't** usar cyberpunk, neón decorativo, glassmorphism o gradientes SaaS genéricos.
- **Don't** repetir filas de tarjetas cuando una composición editorial pueda comunicar mejor.
- **Don't** exponer credenciales de Pexels ni cargar imágenes remotas sin optimización.
